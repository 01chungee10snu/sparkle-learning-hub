# 반짝 배움터

태희와 세희의 수학·국어·영어 학습 게임 런치패드와 공통 학습 기반.

**서비스:** https://01chungee10snu.github.io/sparkle-learning-hub/

## 성장 경로 (v1.1)

과목별 씨앗·새싹·꽃잎·열매 4단계, 12개 성장 놀이와 96문항을 추가했습니다. 총 16개 놀이, 180문항입니다. 첫째는 수학·국어 꽃잎/영어 새싹, 둘째는 씨앗을 초기 추천하며, 실제 풀이에 따라 다음 도전을 제안합니다. 출생연도와 성별을 공개 소스에 저장하지 않습니다.

성장 지도에서 과목별 시작점을 바꿀 수 있습니다. 첫째 5문항/둘째 3문항 회차, 최근 근거 기반 추천, 복습, 그림·듣기, 실물 활동을 지원합니다. 누적 별은 추천과 분리하며 기존 기록·백업과 호환합니다. 자세한 설계·근거·한계는 [CURRICULUM.md](./CURRICULUM.md)에서 확인합니다.

## 기존 게임

| 과목 | 게임 | 내용 | 문항 |
|---|---|---|---:|
| 수학 | 단위 정원 | cm/m/km, g/kg, 백분율 — 기존 앱 연결 | 48 |
| 수학 | 숫자 모험 | 20 이하의 이야기 덧셈·뺄셈 | 12 |
| 국어 | 낱말 탐정 | 문맥에서 알맞은 낱말과 표현 고르기 | 12 |
| 영어 | 단어 소풍 | 과일·동물·색깔, 정답 단어 발음 듣기 | 12 |

## 실행

별도 패키지 설치나 비밀키 없이 정적 파일로 실행합니다.

```sh
npm start
# http://127.0.0.1:4179
npm run check
```

단위 정원 연결까지 로컬에서 검사하려면 두 저장소의 부모(`~/github`)를 서비스합니다.

```sh
cd /Users/01chungee10/github
python3 -m http.server 4180 --bind 127.0.0.1
# http://127.0.0.1:4180/sparkle-learning-hub/
```

GitHub Pages: `main` 브랜치의 `/`. 소스를 커밋·푸시하면 배포됩니다.

## 확장 구조

```text
games/catalog.json             게임 목록과 노출 상태
games/<game-id>/game.json       게임별 문항·정답·해설·그림 데이터
platform/catalog.js            목록·게임 로딩과 형식 검증
platform/progress.js           공통 프로필·기록·점수·백업 어댑터
app.js                         런치패드와 공통 퀴즈 실행 화면
scripts/new-game.mjs           새 게임 초안 생성
scripts/check.mjs              문항과 게임 목록 검증
```

어린이 화면에는 구현된 `published` 게임만 표시합니다. 빈 카드나 개발용 버튼을 노출하지 않습니다. 새 게임 제작 절차는 [ADDING_GAMES.md](./ADDING_GAMES.md)를 참고하세요.

## 프로필과 점수

- `sparkle-learner-v1`: 공통 선택 아이(tae/se)
- `sparkle-learning-progress-v1`: 새 게임별 학습 기록과 진행 중 라운드
- `fairy-math-garden-v1`: 기존 단위 정원의 원본 기록. 별을 읽어 합산하며 별을 이중 복사하지 않습니다.
- 게임별 문항 최대 10점. 처음 정답 10, 처음 오답 후 해설 2, 이후 정답은 차액 8. 복습으로 무한 적립되지 않습니다.
- 새 회차는 첫째 5문제·둘째 3문제를 보관합니다. 기존 진행 중 5문제 회차도 보존합니다. 다른 게임이나 다른 아이로 바꾸어도 재개 가능합니다.
- 상위 플랫폼 보상은 모든 게임의 별을 합쳐 30/100/250/500개에 열립니다. 기존 단위 정원의 자체 보상도 유지합니다.
- 이 기기·브라우저의 저장소만 이용하며 자동 기기 간 동기화는 없습니다. 전체 백업은 플랫폼과 단위 정원 기록을 포함합니다. 가져오기는 문항별 최고점을 병합합니다.
- GitHub Pages 두 앱이 동일 출처 `https://01chungee10snu.github.io`에 있어 선택 아이와 기존 기록을 공유할 수 있습니다. 추후 도메인을 분리하면 별도 저장 연동이 필요합니다.
- 계정 인증, 서버 검증 점수, 학습 분석 추적은 현재 포함하지 않습니다.

## 디자인·접근성

큰 주아체, 반응형 화면, 키보드 초점, 모달 초점 순환, 읽어주기, 감점·시간제한 없는 학습. 수학 뺄셈은 처음 수량 안에서 뺀 수량을 흐리게 표시합니다. 영어 정답 발음은 정답 확인 뒤 제공합니다.

일러스트는 단위 정원의 자체 생성 요정 이미지를 재사용합니다. 주아체는 우아한형제들/SIL Open Font License (`assets/OFL-Jua.txt`).

## 이후 확장

우선 아이들의 반응에 따라 시계·돈 계산·문장 이해·파닉스처럼 학습 목적이 분명한 게임을 추가합니다. 별도 형식의 게임은 공통 프로필/기록 어댑터를 연결해 새 실행기를 추가하거나 외부 앱으로 등록합니다. 필요 시 `platform/progress.js`의 저장 어댑터를 가족 계정 기반 서버 저장으로 교체할 수 있습니다. Supabase 등을 붙일 때 인증과 행 수준 권한을 함께 설계하고 관리자 키는 클라이언트에 넣지 않습니다.

WebMCP 지원 브라우저에서는 게임 목록/진도 읽기와 과목 필터 변경을 제공합니다. 답안 대신 풀기나 별을 임의로 지급하는 도구는 제공하지 않습니다.
