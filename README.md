# 반짝 배움터

태희와 세희의 수학·국어·영어 학습 게임 런치패드와 공통 학습 기반.

**서비스:** https://01chungee10snu.github.io/sparkle-learning-hub/

## Bebsu 수학 문제집 (v1.4)

Bebsu의 수학 문항 3,805개를 12개 학년별 문제집으로 통합합니다. 유아 기초 25문항, 직접 만든 초1 변형 100문항, KMA 원본 3,680문항입니다. 기존 396문항을 포함하면 총 46개 놀이·4,201문항입니다. 정답이 없는 13문항과 공식 정답이 다른 문항에 연결되었거나 복합 답을 요구하는 2문항, 총 15문항은 학습 화면에서 제외합니다.

‘수학 문제집’에서 유아 기초·초1~초6·중등 공통·중1~중3을 직접 선택합니다. 세희는 유아 기초, 태희는 초1부터 보여 주며, 상위 학년은 보호자와 선택하는 연습 자료입니다. 문제집의 점수는 성장 단계의 자동 승급 근거로 사용하지 않습니다.

숫자패드로 정수와 필요한 문항의 음수 답을 입력하고, 원본의 5지선다를 그대로 지원합니다. KMA 문항은 오류가 있는 OCR 문장 대신 원본 문제 그림과 풀이를 보여 줍니다. 그림 확대보기와 풀이 페이지를 제공하며, 원본 정답표만 있는 자료는 해당 번호와 원본 페이지를 안내합니다. 보관본에 빠진 그림은 공식 PDF에서 복구했습니다. 출처·검증 상태·권리 표기와 복구 정보는 [통합 기록](./docs/BEBSU_INTEGRATION.md)에 남깁니다. 원본 정답을 모두 다시 풀어 검증했다는 의미는 아닙니다.

아이별 회차와 기존 별·선물·요정 기능을 공유합니다. 진행 기록은 v2/v1에서 v3로 이관하며 이전 저장 키를 유지합니다. Bebsu의 학생 정보·풀이 이력·지갑·인증 정보는 가져오지 않습니다.

## 요정과 별 선물 (v1.3)

선택한 아이의 요정이 학습 도우미로 함께합니다. 태희는 기존 이미지 왼쪽의 분홍 별 요정, 세희는 오른쪽의 연보라 달 요정입니다. 인사·문제 읽기 도움·재연습·완료를 응원하고, 원본 이미지를 CSS로 분리해 사용합니다. 요정 주변의 Three.js 입체 별·궤도·선물 효과는 로컬로 제공하며 외부 CDN이 필요 없습니다. 30fps와 DPR 1.5 상한, 숨김 상태 정지, 움직임 줄이기, WebGL 불가 시 정적 대체를 적용합니다. 요정 초상은 2D이고 주변 효과는 3D입니다.

- 기존 문제 별과 단위 정원 원본 키를 그대로 보존합니다.
- **평생 모은 별**은 학습 별과 제한된 노력 별의 합이고, **쓸 수 있는 별**은 여기서 선물 지출을 뺀 값입니다. 선물 구매로 성장 기록은 줄어들지 않습니다.
- 풀이 후 재연습 정답은 1별, 문항당 평생 노력 별은 최대 2개입니다. 배움터 회차 완주는 한국 날짜 기준 하루 최대 3별입니다. 힌트·오답·결석으로 차감하지 않습니다. 풀이 뒤 재연습 결과는 성장 추천의 초기 풀이 기록에 넣지 않습니다.
- 30/60/100별로 별 꼬리·빛 고리·혜성 장식, 40/80/120별로 함께 읽기·산책·소풍 의논을 신청합니다. 가족 활동은 신청할 때 쓸 수 있는 별을 사용하고, 보호자가 실제 함께한 뒤 완료를 표시합니다. 기본 돌봄이나 애정은 보상 조건이 아닙니다.
- 첫 완주·세 과목 탐험·다시 풀어 맞힘·서로 다른 두 날의 정답을 실제 기록에서 확인한 배지로 표현합니다. 발달/숙달 진단이 아닌 앱 내 성취 기록입니다.
- 보상 원장은 `sparkle-rewards-v1`에 아이별로 분리하며 기존 전체 JSON 백업에 포함됩니다. 보상 없는 과거 백업도 유지·병합됩니다. 같은 장식/진행 중 가족 신청은 중복 차감하지 않습니다.

모바일은 게임 목록을 한 카드씩 넘기고, 태블릿/데스크톱은 세 카드씩 봅니다. 문제와 풀이를 다른 화면으로 표시하고 풀이 문단을 순서대로 넘깁니다. 기록 목록도 페이지로 나눕니다. 일반 세로 모바일/태블릿은 100dvh 작업 화면을 사용하고, 작은 가로 화면·글자 확대에서는 접근성을 위해 스크롤을 허용합니다. 모든 원래 해설은 보존합니다.

가격과 노력 별 상한은 초기 운영 가정입니다. 아이가 별 자체에만 몰두하는지, 새로운 방법을 설명하는지 살펴보며 조정합니다. 선택권·달성 가능한 도전·과정 피드백·실제 상호작용에 관한 근거: [Harvard Center on the Developing Child](https://developingchild.harvard.edu/resources/briefs/how-to-motivate-children-science-based-approaches-for-parents-caregivers-and-teachers/). 이 앱의 보상 시스템 자체의 효과를 검증한 연구는 아닙니다.

## 생활 모험과 성장 경로 (v1.2)

18가지 주제의 생활 모험을 각 12문항씩 추가했습니다. 총 34개 놀이, 396문항입니다. 배움터 내부 33개 놀이·348문항과 외부 단위 정원 1개·48문항을 합친 수입니다.

| 구성 | 놀이 | 문항 |
|---|---:|---:|
| 생활 모험 | 18 | 216 |
| 과목별 4단계 기초 경로 | 12 | 96 |
| 기존 배움터 게임 | 3 | 36 |
| 외부 단위 정원 | 1 | 48 |
| 합계 | 34 | 396 |

보기 고르기·수량 쌓기·순서 놓기·짝 연결·순서 기억의 다섯 놀이 방식을 지원합니다. 첫 화면은 현재 과목별 단계와 진행 기록을 참고해 수학·국어·영어 모험을 하나씩 보여 줍니다. ‘다른 모험 만나기’로 바꾸거나 ‘모두 보기’에서 과목·놀이 방식으로 고를 수 있습니다.

기초 경로는 씨앗·새싹·꽃잎·열매 4단계입니다. 첫째는 수학·국어 꽃잎/영어 새싹, 둘째는 씨앗을 초기 추천하며, 기초 경로의 실제 풀이에 따라 다음 도전을 제안합니다. 모험의 별도 합산하지만 모험 점수를 단계 상승의 근거로 사용하지 않습니다. 출생연도·성별·실제 기관명은 공개 소스에 저장하지 않습니다.

성장 지도에서 과목별 시작점을 바꿀 수 있습니다. 첫째 5문항/둘째 3문항 회차, 최근 근거 기반 추천, 복습, 그림·듣기, 실물 활동을 지원합니다. 누적 별은 추천과 분리하며 기존 기록·백업과 호환합니다. 자세한 설계·근거·한계는 [CURRICULUM.md](./CURRICULUM.md)에서 확인합니다.

## 실행

배포된 앱은 별도 설치나 비밀키 없이 정적 파일로 실행합니다. Three.js 0.180.0은 vendor에 고정하여 제공합니다. 의존성 갱신 시 npm install 후 build/three.module.min.js와 build/three.core.min.js를 함께 vendor에 복사하고 라이선스를 유지합니다.

```sh
npm start
# http://127.0.0.1:4179
npm run check
```

단위 정원 연결까지 로컬에서 검사하려면 두 저장소의 부모(`~/github`)를 서비스합니다.

```sh
cd /Users/01chungee10/github
python3 -m http.server 4180 --bind 127.0.0.1
# http://127.0.0.1:4180/sparkle-learning-hub/
```

GitHub Pages: `main` 브랜치의 `/`. 소스를 커밋·푸시하면 배포됩니다.

## 확장 구조

```text
games/catalog.json             게임 목록·단계·놀이 방식·노출 상태
games/<game-id>/game.json       게임별 문항·정답·해설·그림·활동 데이터
platform/catalog.js            목록·게임 로딩과 형식 검증
platform/activities.js         다섯 놀이 방식의 답 형식 검증·채점
platform/activity-ui.js        수량·순서·짝·기억 놀이 화면
platform/growth.js             기초 경로의 단계·복습 추천
platform/progress.js           공통 프로필·기록·점수·백업 어댑터
platform/settings.js           기기 내 장소 설정·개인화
app.js                         런치패드와 공통 학습 실행 화면
scripts/new-game.mjs            선택형 새 게임 초안 생성
scripts/check.mjs               문항과 게임 목록 검증
```

어린이 화면에는 구현된 `published` 게임만 표시합니다. 빈 카드나 개발용 버튼을 노출하지 않습니다. 새 게임 제작 절차는 [ADDING_GAMES.md](./ADDING_GAMES.md)를 참고하세요.

## 프로필과 점수

- `sparkle-learner-v1`: 공통 선택 아이(tae/se)
- `sparkle-learning-progress-v3`: 게임별 학습 기록과 진행 중 회차. v2/v1 기록을 이관해 사용하며, 구버전 탭과 저장 공간을 분리합니다. 이전 키는 수정하지 않습니다.
- `sparkle-family-settings-v1`: 두 아이의 이야기 속 장소 이름
- `fairy-math-garden-v1`: 기존 단위 정원의 원본 기록. 별을 읽어 합산하며 별을 이중 복사하지 않습니다.
- 게임별 문항 최대 10점. 처음 정답 10, 처음 오답 후 해설 2, 이후 정답은 차액 8. 복습으로 무한 적립되지 않습니다.
- 새 회차는 첫째 5문제·둘째 3문제를 보관합니다. 기존 진행 중 5문제 회차도 보존합니다. 다른 게임이나 다른 아이로 바꾸어도 제출한 답과 현재 문항부터 재개 가능합니다. 제출 전 쌓기·배치 작업은 영구 저장하지 않습니다.
- 상위 플랫폼의 누적 별자리는 모든 게임과 노력 별을 합쳐 30/100/250/500개에 열립니다. 선물 지갑과 구매 원장은 별도로 유지합니다. 기존 단위 정원의 자체 보상도 유지합니다.
- 이 기기·브라우저의 저장소만 이용하며 자동 기기 간 동기화는 없습니다. 전체 백업은 플랫폼과 단위 정원 기록, 아이별 별 지출·장식·가족 신청, 두 아이의 장소 설정을 포함합니다. 가져오기는 문항별 최고점과 보상 원장을 병합하고, 장소 설정이 있으면 가져온 값으로 반영합니다. 오래된 백업에 장소 설정이 없으면 현재 설정을 유지합니다.
- GitHub Pages 두 앱이 동일 출처 `https://01chungee10snu.github.io`에 있어 선택 아이와 기존 기록을 공유할 수 있습니다. 추후 도메인을 분리하면 별도 저장 연동이 필요합니다.
- 계정 인증, 서버 검증 점수, 학습 분석 추적은 현재 포함하지 않습니다.

## 우리 이야기의 장소

보호자 안내에서 학교·어린이집 이름을 바꾸면 `{{place}}`가 있는 이야기에 반영합니다. 공개 자료에는 ‘우리 학교’·‘우리 어린이집’과 같은 기본 표현만 사용하고 실제 기관명을 커밋하지 않습니다. 설정은 현재 브라우저에 저장되며 서버에 업로드하지 않습니다.

개인화 설정 링크는 `#family=` fragment를 읽은 뒤 주소에서 제거합니다. fragment의 내용은 암호화된 비밀정보가 아니므로 설정 링크를 공개 게시하지 않습니다. **내보낸 JSON에도 장소명이 포함되므로** 기록 파일을 공유하기 전 내용을 확인합니다. 개인화된 이야기는 실제 기관의 수업·시간표를 재현한 자료가 아닙니다.

## 디자인·접근성

큰 주아체, 반응형 화면, 키보드 초점, 모달 초점 순환, 읽어주기, 감점·시간제한 없는 학습. 활동은 드래그 없이 누르기로 조작합니다. 기억 놀이는 준비되면 가리고 언제든 다시 살펴볼 수 있습니다. 수학 뺄셈은 처음 수량 안에서 뺀 수량을 흐리게 표시합니다. 영어 듣기 문제의 자극과 짝 연결 낱말은 풀이 중 들을 수 있고, 정답 발음은 정답 확인 뒤 제공합니다.

일러스트는 단위 정원의 자체 생성 요정 이미지를 재사용합니다. 주아체는 우아한형제들/SIL Open Font License (`assets/OFL-Jua.txt`).

## 이후 확장

아이들의 반응에 따라 현재 주제의 상황·문항을 늘리고, 필요한 개념을 추가합니다. 새로운 활동 형식은 공통 채점·프로필·기록 어댑터와 연결하거나 외부 앱으로 등록합니다. 필요 시 `platform/progress.js`의 저장 어댑터를 가족 계정 기반 서버 저장으로 교체할 수 있습니다. Supabase 등을 붙일 때 인증과 행 수준 권한을 함께 설계하고 관리자 키는 클라이언트에 넣지 않습니다.

WebMCP 지원 브라우저에서는 게임 목록/진도 읽기와 과목 필터 변경을 제공합니다. 답안 대신 풀기나 별을 임의로 지급하는 도구는 제공하지 않습니다.
