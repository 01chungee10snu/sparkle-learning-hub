# 적응형 학습 코드 변경 기록 · 2026-10-10

## 변경 범위
- 반짝 배움터의 4,153개 내부 문항에 대해 재현 가능한 문항 메타데이터를 구성하고 정답률·난이도 기반 회차를 적용
- 외부 단위 정원 48개는 별도 저장소의 독립 모형으로 출제 조정
- Bebsu 3,805개 포함. 이전 통합에서 제외한 오류 가능 15개 문항은 재편입하지 않음
- 원본 문항, 그림, 공식 정답 키, 별 지급 기준, 기존 백업 형식은 변경하지 않음

## 학습 로직
1. 문항을 단계/학년/개념/유형/기존 검증 수준으로 분류하고 잠정 난이도 값을 부여
2. 아이·과목별로 처음 응답이 독립적이었던 서로 다른 문항만 사용하여 1PL형 베이지안 능력 추정
3. 현재 능력에 따른 예측 정답률 60~85% 부근의 문항을 혼합 배치
4. 새로운 문제와 개념 다양성을 우선하고, 독립 응답에서 어려움이 관찰된 개념에는 제한적인 재연습 가중치 적용
5. 연속 정답으로 보상은 유지하지만 능력 근거는 중복 계산하지 않음
6. 최근 정답률·완료 회차·서로 다른 풀이 문항·모형 예측을 충족하면 다음 성장 단계/학년을 **제안**. 성장 지도에 저장하는 단계와 문제집 학년은 직접 선택하며, 추천 모험의 출제 수준은 준비도에 따라 조정

## 검증
- `npm run irt:build` : 문항 색인 및 점검자료 생성
- `npm run check` : 전체 문항 구성, 정답 검증, 각 학습형식, 성취도·적응형 출제, 기존 별·백업·프로필 분리, 마법마을 연결 테스트
- 별도 단위 정원: `npm run check`
- `docs/IRT_QUESTION_AUDIT_20261010.md`: 문항 검토 상태 및 한계
- `docs/IRT_ITEM_INVENTORY.csv`: 문항 단위 품질/난이도 색인

## 검증 한계
현재 문항 b/추측 확률은 교육 콘텐츠 기반 **초기 운영 가정**이며 경험적으로 보정된 IRT 모수가 아닙니다. 대규모 학습자 반응이 없어 실증적 문항변별도, 문항편향(DIF), 표준오차의 타당도를 검증하지 못했습니다. KMA 원문·그림의 정답을 모두 인간 전문가가 독립적으로 재풀이한 것도 아닙니다. 현재는 개인 맞춤 학습 권고와 재연습 경로에만 사용합니다.
