# 마법마을 v27 · 직업사전 100개와 학습 화폐

2026-10-19 작성 · 실제 근거를 표시하는 어린이용 직업 학습 콘텐츠

## 1. 공식 직업정보의 두 출처

- **한국직업사전**(한국고용정보원/워크넷): 수행 직무와 자격·교육, 분류체계 참조. https://www.work.go.kr/consltJobCarpa/srch/jobDic/jobDicIntro.do
- **커리어넷 직업백과**(교육부·한국직업능력연구원, 임금출처 워크넷/임금직업포털): 개별 직업의 임금 중앙값·조사연도·종사자 학력분포·직업분류 코드. https://www.career.go.kr/cloud/m/job/list
- 본 콘텐츠의 각 직업 임금은 커리어넷 공식 직업 상세 JSON의 공개 **숫자 정보**에서 추출했다. 직무 개요/체험 미션은 아이에게 맞추어 자체 작성했으며 정부의 서술 원문을 복제한 것이 아니다.
- `village/career-data-v27.js`: 100개 기록과 직업별 출처 URL·임금 조사연도·시간당 환산액·직업분류 코드·관련 직업 임금 대체치 여부.
- `docs/CAREER_V27_SOURCE_AUDIT.json`: 각 직업의 값 및 provenance 감사. 원천 552개 직업 중 임금 수치가 있는 478개에서 특정 100개를 골랐다. **임의가 아닌 전체 직업 대표 표본이 아니다.** 분류명을 모든 한국직업사전 항목에 일대일 대조 완료했다고 주장하지 않는다.
- 100개 직업 중 96개는 2021년, 4개는 2023년 임금 자료이다. **43개는 정확한 같은 직업의 관측치가 아닌 관련 직업의 대체 임금**이다. 장기 비교, 조사연도 혼합, 직업 내 개인 편차 때문에 임금순 정렬의 인과적·규범적 해석은 금지한다.

## 2. 시간당 환산과 학업 수준

- API가 `wage`로 제공하는 금액은 **연봉 중앙값(만원)**으로 출처에 명시되어 있다. 평균 임금이라고 부르지 않는다.
- `시간당 단순 환산(원) = 연봉 중앙값(만원) × 10,000 ÷ 2,080`. 2,080시간은 **주 40시간 × 52주**의 일률적인 비교 가정. 초과근무·유급휴가·실제 일한 시간·사업 소득·복리후생은 반영되지 않는다. 이는 **실제 평균 시급도, 이 직업을 얻으면 벌게 될 금액도 아니다**.
- 커리어넷 `jobEduChart`(중졸 이하/고졸/전문대졸/대졸/대학원졸/박사졸)의 현재 종사자 표본 학력 백분율을 제시하며, 그 출처를 별도 표시한다.
- 직업별 학생 시험석차·입학 합격 순위 “1만 명 중 몇 등”의 검증 가능한 공인 단일 지표는 발견되지 않았으므로 전체 100개에 **NULL / 공식 통계 없음**으로 기록한다. 종사자의 학력분포를 학생 입직 문턱·시험 석차로 바꾸지 않는다.
- **OECD Education at a Glance 2025 한국**의 고등교육 이수 집단과 고졸 집단 소득차 **평균 +31%**는 집단 연관성이지 개인의 성적 향상이 임금을 초래한다는 인과 실험이나 소득 보장이 아니다. 연령·성별·전공·기회·노동시장 조건 등에도 영향을 받는다. https://www.oecd.org/en/publications/education-at-a-glance-2025_1a3543e2-en/korea_252c9ed2-en.html

## 3. 편향 최소화 원칙

1. 초기 기본 정렬은 **선정 100개 직업 내 출처가 있는 연봉 중앙값 내림차순**. 가나다순·오름차순·6개 직업 분야 검색 지원. 사회적 위세·인간적 가치의 순위가 아니다.
2. 의료/공학/법률/경제·경영/교육·창작/생활·환경·미래의 6개 분야에서 고임금부터 저임금까지 폭넓게 수록. 특정 학교 성적·가정 배경·성별·지역·출신을 단정하지 않는다.
3. 직업의 소득과 개인의 학업 점수 사이에 상관/인과관계를 직업 단위로 검증하지 않았다. 임의 등수를 만들거나 한 직업이 다른 직업보다 사회적으로 더 존엄하다고 표현하지 않는다.
4. 각 상세 화면에 연봉의 중앙값/연도, 관련 직업 대체값 경고, 응답자 학력의 관측치, 근거 URL, 계산식을 함께 표시한다.
5. 선택에서 빠진 직업도 한국직업사전·커리어넷 **무료 공식 링크로 접근**할 수 있도록 제공한다.

## 4. 화폐 보상

- 아동별로 수학 수정 💎·국어 꽃잎 🌸·영어 깃털 🪶·한자 먹방울 🖋️ 적립.
- 누구나 **무료**로 직업명·직무 개요·사회적 기여·준비 과목·체험 미션·공식 원문 링크를 열람할 수 있다.
- 실제 공식 임금·시간당 환산·학력분포를 **마을 내 게임 UI에서 깊게 탐험**할 때, 서로 다른 두 과목의 화폐 **각 1개(총 2개)**를 사용한다. 여섯 쌍 중 적립된 조합을 자유롭게 선택할 수 있다.
- **100개 직업의 상세 가격은 모두 동일**. 고임금 직업일수록 비싸거나 싸지 않다. 국어+수학처럼 아이에게 접근 가능한 조합도 포함하며 한자 의무는 없다.
- 화폐는 문제를 독립적으로 풀어 얻는 **게임 점수**이고 법적 가치나 구매 가능한 외부 화폐가 아니다.
- 영구 해금은 `platform/resource-economy.js`에서 각 아이의 불변 영수증으로 기록. 중복 클릭해도 한 번만 차감, 모바일 재접속 시 상태 유지. 기존 별과 물고기·정원 지출은 보존. 동일 스냅샷 병합 시 동일 해금은 한 번만 계산.
- Supabase 가족 동기화 스냅샷에 `careerUnlocks` 영수증을 포함. 백엔드가 화폐 채굴을 검증하는 실물 거래 시스템이 아니므로 재정적 가치, 거래, 실제 결제 기능은 존재하지 않는다.

## 5. 데이터 재현 및 QA

- `python3 scripts/research-careernet-wage-list-v27.py`가 공개 커리어넷 552개 직업의 숫자 목록만 /private/tmp 임시파일로 가져온다.
- `python3 scripts/build-career-dictionary-v27.py`가 수작업 검토한 `scripts/career-curation-v27.tsv`의 100개 고유 직업을 개별 공식 직업 API 100건으로 검증하고 정적 데이터/감사 JSON을 재생성한다.
- `npm run check`와 `scripts/check-season-career.mjs`에서 100개 직업 원천 출처·독립 학습자·해금/영수증·문항·IRT 재검증.
- `node scripts/qa-career-100-tokenomics-v27.mjs`: 갤럭시 390×844, 태블릿 768×1024 브라우저에서 무료 개요, 숨겨진 소득 통계, 두 과목 코인 1+1, 해금·재접속·태희/세희 기록 격리 검증.
- `scripts/qa-cloud-resources-v23.mjs`: 별도 기기 두 대의 백업 병합 및 직업 해금 2건을 포함한 모의 Supabase API 검증; 실기 두 기기의 원격 서비스 인증 성공을 의미하지는 않음.
