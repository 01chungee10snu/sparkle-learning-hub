# 마법 마을 학습 촉진 루프 v13 — 2026-10-15

## 목적

마법 마을의 성공 지표를 체류시간·클릭·별 소비가 아니라 **기억의 유지, 독립적인 재인출, 적정 난도 도전, 다른 맥락으로의 전이**에 둔다.

## 학습 루프

1. **다시 떠올리기(Retrieval)**
   - 힌트 없이 독립적으로 시도한 기록을 사용한다.
   - 마지막 독립 시도가 오답이면 즉시 다시 연습할 수 있다.
   - 정답을 독립적으로 반복하면 복습 간격을 `2 → 4 → 7 → 14 → 30일`로 확장한다.
   - 힌트를 사용한 정답은 독립 회상 성공으로 계산하지 않는다.

2. **알맞은 도전(Productive challenge)**
   - 기존 IRT 1PL+guessing 잠정 모델의 문항 선택을 그대로 사용한다.
   - 기술적으롔 관찰된 개념별 gap은 다음 연습의 우선순위에만 사용한다.
   - 학년·단계 자동 승급, 능력·IQ·발달 진단에 사용하지 않는다.

3. **다른 곳에 써보기(Transfer)**
   - 같은 skill 태그를 공유하는 다른 adventure를 우선 선택한다.
   - 동일 개념을 다른 이야기·활동 양식에서 다시 사용하게 한다.
   - 적절한 동일-skill 모험이 없으면 현재 단계의 덜 플레이한 다른 맥락을 선택한다.

4. **내 말로 다시 설명하기(Teach-back)**
   - 회차 종료 후 목적에 맞는 짧은 생성적 회상 질문을 제시한다.
   - 복습: 화면 없이 방법 설명
   - 도전: 가장 생각이 필요했던 문제의 풀이 이유 설명
   - 전이: 같은 방법을 다른 상황 어디에 쓸 수 있는지 설명
   - 기존 offline 실물 활동은 별도 유지한다.

## 아이의 선택권

`균형 성장 / 수학 집중 / 이야기 집중 / 영어 탐험 / 정원 돌보기` 육성 목표는 추천 **과목 비중**에만 영향을 준다.
난이도는 육성 목표나 별의 양으로 올리지 않고 실제 풀이 근거와 기존 IRT 경로만 사용한다.

과목 필터를 직접 선택하면 그 선택을 즉시 학습 의도로 간주해 해당 과목 중심으로 오늘의 계획을 다시 계산한다.

## 게임 UX

- 학습 허브 첫 화면: `옫k��의 3걸음`
- Unity 마을 상시 바로가기: `🧠 오늘의 3걸음`
- 기존 자유 탐험, 이야기, 정원, 별 상점은 삭제하지 않는다.
- 학습 루프를 강제로 3개 모두 수행시키지 않는다. 한 단계만 수행하고 쉬어도 된다.

## 데이터 원칙

복습 스케줄의 근거는 `attempt.at`, `correct`, `assisted`이다.
기기 간 동기화 시 이 원자료를 보존하면 복습 시점은 새 기기에서도 재계산할 수 있다.
추천 결과 자체를 영구적인 능력값으로 저장하지 않는다.
