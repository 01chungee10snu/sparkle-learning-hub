## 학습 강화 별 지급

| 행동 | 원장 증거 | 지급 한도 | IRT 반영 |
|---|---|---|---|
| 완료한 한 회차를 설명한 방법 선택 | 해당 학습자의 실제 `completedRounds[].id` + 전략 코드 | +2별, 회차당 1회, 하루 2회 | 반영 안 함 |
| 오답을 다른 회차에서 처음 정답으로 교정 | 문항 `firstAttempt.correct=false`, 이후 **다른 roundId**의 정답 시도 | +4별, 해당 문항 최초 1회, 하루 최대 3건 | 최초 독립 응답 외 추정 반영 안 함 |
| KMA 경시 시험지 25문항 완주 | 학년·paperId·1~25번 완료 증빙 | 태희 +160, 세희 +60, 동일 시험지 최초 1회 | 별 지급 자체는 능력 추정에 영향 없음 |

- 전략 코드: `count,compare,pattern,draw,explain`. 자기보고로 풀이 **설명 행동**을 격려하며 설명 원문·음성·오디오 녹취는 수집하지 않음.
- 기존 영구 보상 원장 `sparkle-rewards-v1`의 버전 1 유지, 추가 이벤트 종류 `explain`, `recovery`를 **검증 후** 허용.
- 기존 별 지급·구매·형제 분리·영수증 머지는 유지. 새 기록은 보상 백업으로 내보내기/가져오기 가능.
- 브라우저 로컬 스토리지 기반으로 개발자 도구를 통한 위조가 가능한 시제품이며 서버 신원 인증·부정행위 방지로 오해해서는 안 됨.

## 조작형 학습

- 기존 3개 세계관 스킨(마법책·의뢰서·수정판) 유지.
- `choice` 또는 `build` 일반 문제 중 문항 ID를 고정 해시하여 **대략 40%**를 마법문/마법 바구니 조작으로 제시.
- 정답 값은 기존 `Progress.answerQuestion` 그대로 사용. 공간 UI가 별 지급·채점·IRT 문항 파라미터를 직접 변경하지 않음.
- KMA 원본 25문항은 출처 그림, 1~25번 순서, 160/60 보너스 유지. 원본 지면을 임의로 3D 조작 문제로 대체하지 않음.
- 태희·세희 모바일 시연에서 4개 HUD 단축/학습 버튼 및 북 UI 외에 원래의 자세한 문제 그림의 판독성을 유지.

## 8방향 캐릭터 원화 — 품질 사실관계

**완전한 고해상도 독립 8방향 원화로의 최종 교체는 아직 완료되지 않음.**

- 태희/세희 각각 진짜 8개 방향으로 그려진 그림을 Canva에서 생성함.
- 연결 가능한 Canva 미디어: 태희 `MAHXnCslfsw`, 세희 `MAHXm96VFnA`; 원본 메타데이터는 1536×1024이나 연결된 API가 전체 해상도 원본 다운로드를 제공하지 않음.
- 로컬로 접근 가능한 **200×133px 축소 미리보기**를 `Assets/Art/Generated/Directional/EightView/`에 보존하고 16개 독립 방향으로 분리·투명화·시제품 스프라이트 아틀라스를 생성함.
- 저해상도 복원으로 누락된 원화 세부 묘사는 복구되지 않음. **기본은 이전 고화질 4방향, 사이 4방향 합성**을 유지하고, `🎭 8방향 시안` 버튼으로만 독립 8시점을 비교하도록 제공. `🎨 고화질 원화`를 누르면 즉시 복귀.
- 원본 1536×1024를 직접 다운로드해 전달/연결한 뒤 시각검수(헤어/의상/시점 일치, 원본 투명도, 스프라이트 pivot) 후 기본 모드로 전환할 것. 생성 완료 이미지 자체와 현행 로컬 8방향 시제품 품질을 혼동하지 않음.
