## 동기화 모델

v20은 snapshot-first sync를 사용한다.

1. 보호자 로그인
2. `bootstrap_magic_family()`로 가족/태희/세희 row 확인 또는 최초 생성
3. 브라우저 device 등록
4. 가족의 **각 device별 최신 snapshot**을 조회
5. 현재 기기의 local state와 모두 merge
6. merge 결과의 SHA-256 계산
7. 내용이 새로울 때만 새 snapshot 업로드

### 왜 가족 최신 1개가 아니라 device별 최신인가

두 기기가 동시에 오프라인에서 서로 다른 학습을 한 경우:

- A snapshot = 기존 + A 변화
- B snapshot = 기존 + B 변화

가족 최신 1개만 읽으면 한 branch가 누락될 수 있다.

따라서 다음 sync에서 각 device의 최신 snapshot을 모두 읽고 합치면:

`기존 + A + B`

로 eventual convergence가 가능하다.

## merge 규칙

서버 snapshot을 localStorage에 덮어쓰지 않는다.

기존 검증된 merge API를 재사용한다.

- Progress: attempt / completed round 합집합
- Rewards: progress evidence 검증 후 event merge
- Village: completion/event merge
- Growth goals: 기존 progression merge
- Relationships: event ID union
- Skill Ecology: raw skill memory event union
- Family settings: 현재 기기가 기본값일 때만 원격 설정 적용

파생값인 기억 반감기, 관계 level, habitat tier는 서버 snapshot에 authoritative 값으로 고정하지 않는다. 원사건에서 다시 계산한다.

## 자동 동기화

로그인 상태에서는:

- 앱 시작 시 1회 auto sync
- 마법마을 직접 진입 시 1회 auto sync
- 화면 상태가 바뀐 뒤 4초 동안 추가 변화가 없으면 debounced auto sync
- 여러 sync 호출은 single-flight로 합친다.
- 수동 `지금 동기화`도 제공한다.

네트워크 오류가 나도 local 기록은 그대로 유지한다.
