# 마법마을 모션·원화 확장 v16 — 2026-10-15

## 목표

기존 고해상도 태희·세희 원화를 보존하면서 정지 행동 원화와 이동 중 시각 효과를 확장해 반복 플레이의 시각적 단조로움을 줄인다.

## 원화 전략

새 캐릭터 정체성을 만들지 않고 기존 프로젝트 고해상도 원화와 이미 제작된 이펙트 자산만 재조합했다.

기본 원본:
- `taehee_original.png`
- `sehee_original.png`

재사용 이펙트:
- magic dust
- yellow / purple / rainbow star
- heart
- bloom / seed / sprout
- butterfly
- gift
- book badge

8방향 프로토타입은 방향 검증용으로 유지한다. 저해상도 preview를 고해상도 기본 캐릭터로 승격하지 않는다.

## 정지 행동 비네트

태희 8종 + 세희 8종 = 총 16종.

- Celebrate — 정답/완주 축하
- Think — 오답 후 사고·회복
- Cast — 학습 지역/퀘스트 진입
- Wave — 인사
- Care — 나무·꽃 돌보기
- Discover — 새로운 성장/지역 발견
- Focus — 문제 집중
- Receive — 새 선물/장식 반응

파일:
`Assets/Resources/Sprites/Motion/{tae|se}_{state}.png`

생성 스크립트:
`scripts/Art/compose_motion_vignettes.py`

manifest:
`Assets/Resources/Sprites/Motion/motion-vignette-manifest.json`

## 이동 모션

방향 원화를 유지한 채 procedural layer를 사용한다.

- Idle — 느린 breathing + 간헐적 sparkle
- Walk — 발밑 소형 magic dust
- Run — 더 강한 dust + 반투명 afterimage
- Hop — landing sparkle
- Interact — 손/상단 방향의 약한 magic accent

정지 행동 원화와 이동 원화를 분리해 방향 이동 중 정면 캐릭터가 갑자기 나타나는 현상을 방지한다.

## 이벤트 매핑

- 문제 시작 → Focus
- 정답 → Celebrate
- 오답 → Think
- 학습 지역 진입 → Cast
- 정원 진입/돌봄 → Care
- 학습 완료로 마을 성장 → Discover
- 장식 변경 → Receive
- 사용자 인사 → Wave
- 달리기/점프 → Run/Hop

## 접근성

사용자의 reduced-motion 설정은 기존대로 우선한다. 모션 확장은 학습 정답이나 진급 조건을 바꾸지 않고 시각 피드백만 강화한다.

## 다음 확장 후보

현재 비네트는 기존 원화의 재조합이다. 향후 Artcraft 또는 고해상도 원화 제작 경로가 연결되면 다음을 독립 포즈 원화로 교체할 수 있다.

- 실제 팔을 드는 Wave
- 몸을 숙이는 Care
- 책/문제를 보는 Focus
- 마법봉 동작이 큰 Cast
- 두 팔을 드는 Celebrate

그 경우에도 동일한 motion ID와 runtime contract를 유지해 코드 변경 없이 원화만 교체한다.
