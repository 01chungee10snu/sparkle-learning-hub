# 마법마을 v26 — 게임 타이틀·계절 섬·미래 직업 탐색관

업데이트: 2026-10-19

## 사용자에게 제공되는 화면

- 루트: **마법마을 입장하기** / **학습페이지 가기** 두 개의 큰 게임 포털
- 3D 로비: 요정(태희·세희) 선택, 3D 마법마을 입장, 낮은 사양용 가벼운 2D
- 플레이 화면: 왼쪽 조작 버튼, 건물별 과목·급수 간판, 별 대신 과목별 화폐 잔액, 3D 바다 위 둥근 마법섬
- 2D와 3D에서 같은 문제·IRT·자녀별 누적 저장소를 사용합니다.

## 한국 시간·계절 연출 (실제 일출/일몰 천문시각은 아님)

`village/korea-season-clock.js`의 Asia/Seoul / UTC+09:00 기준:

| KST | 연출 |
|---|---|
| 05:00 ~ 08:59 | 일출 |
| 09:00 ~ 16:59 | 낮 |
| 17:00 ~ 19:59 | 일몰 |
| 20:00 ~ 04:59 | 밤 |

봄(3~5월), 여름(6~8월), 가을(9~11월), 겨울(12~2월) 배경 장식을 바꿉니다. 외국 시간대나 사용자의 임의 기기 시간대에 맞추지 않으며 인터넷 위치 접근은 요구하지 않습니다. 기기 시계가 크게 틀리면 연출도 틀릴 수 있습니다.

Unity 환경: `Assets/Scripts/VillageIslandEnvironment.cs`의 둥근 섬 메시, 절벽, 주변 바다, 물결과 계절별 꽃·나무 색 변화. `VillageRuntime.OnEnvironmentMessage`가 웹 호스트에서 확인한 시즌과 KST 주간을 받아 적용합니다.

## 미래 직업 탐색관

- 의료·생명, AI·공학·우주, 법·국제사회, 경제·경영, 교육·창작, 환경·미래의 6영역에서 **30개 직업**을 소개합니다.
- 아이를 위한 자체 서술로 무엇을 하는지, 다른 사람에게 어떻게 기여하는지, 어떤 공부를 준비하는지, 오늘 해 볼 활동을 제시합니다.
- 높은 전문성·책임·사회적 영향력과 경제적 기회가 가능한 여러 직업을 적극 소개하지만, 객관적 근거 없는 연봉 숫자나 직업별 위세 순위를 만들어 내지 않습니다. **성과·수입·진입 조건은 보장하지 않습니다.**
- 한국의 공식 직업 탐색 서비스인 [커리어넷](https://www.career.go.kr/)과 [고용24](https://www.work24.go.kr/)를 보호자 참고 링크로 제공합니다.
- 태희·세희의 꿈 후보는 독립적으로 저장하고, 삭제까지 병합되는 가족 클라우드 스냅샷에 포함됩니다.
- 3D에서는 직업 탐색관 건물에 다가간 다음 열립니다. 2D에서는 모험 지도로 접근합니다.

## 품질·보존

- 수학/국어/영어/한자 학습과 급수형 8급~3급 IRT, 뱁수·KMA 경시대회 25문항 및 연습 25문항의 기존 데이터를 삭제하지 않았습니다.
- 기존 별 선물·영수증은 과거 호환을 위해 남고, 새 생명 연못 보상은 4종 과목 화폐를 조합하도록 유지했습니다.
- 가족 Supabase 실제 DB migration은 2026-10-17 실행됐지만, 가족 실기 2대 동기화 성공은 별도로 확인해야 합니다. HTTP에서는 페어링 코드를 입력할 수 없습니다.
- GitHub Pages는 HTTPS 기반. 공개 전에는 외부 출처 Hanja 등급 데이터의 재배포 권리 및 Bebsu 문제·원화 사용 범위를 권리자 기준으로 재확인해야 합니다. `rycont/hanja-grade-dataset`의 README가 원자료의 저작권을 한국어문회에 귀속시킨다고 명시합니다. 이 사이트는 한국어문회 공식 앱이 아닙니다.
- 아동의 진로 선택은 실제 직업 적성 판정이나 진학 예측이 아니며, 다양한 직업에 대한 존중을 권장합니다.
