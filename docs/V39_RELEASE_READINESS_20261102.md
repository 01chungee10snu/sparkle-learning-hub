## 검증 과정의 추가 조치

1. 과거 `scripts/unified-village-browser-qa.mjs`는 `/`에서 자동으로 `/village/`로 이동한다는 구형 가정을 사용. 현재는 **학습자 선택 랜딩**이므로 실제 `village/?who=...&autostart=1` 경로로 수정.
2. 과거 동기화 QA는 `progress.js?v=pond-v34`를 별도로 임포트해 최신 학습 모듈과 서로 다른 메모리 인스턴스를 생성. **현재 import map을 따르는 유일한 모듈**을 사용하도록 변경 후 양방향 충돌 재시도 검증 통과.
3. 화면의 `vh-learning-districts`는 게임 화면에서 숨겨지는 기존 설계. 3D 공간을 가로막지 않는 `모험 지도`에 누락된 **마법 수학 훈련장·마법학교·성장의 탑**을 추가하여 아이가 직접 이동 가능하게 함.
4. GitHub Pages의 JavaScript `Cache-Control`이 `max-age=600`인 것을 확인. 새 모듈을 오래된 코드로 로드하지 않도록 루트·학습·마을 세 HTML의 **IRT·Progress·숫자 입력·웹 UI 모듈 쿼리 버전**을 v39로 갱신.

## 운영 데이터 안전 계약

- `games/`, `games/irt-bank.json`, 원본 KMA 기출·정답·해설, Unity `Build/` 바이너리, Supabase SQL, 동기화 스키마는 변경하지 않음.
- `platform/progress.js`, `platform/cloud-sync.js`, 학습/보상 로컬스토리지 키 및 데이터 마이그레이션도 변경하지 않음.
- 두 사용자(`tae`, `se`)의 진도 데이터는 별도로 유지; 복수 기기에서도 기존 가족 동기화 연결이 있는 경우에 한해 승계.
- 동기화 모의 서버 통과는 **실제 운영 서버로 기록을 업로드했다는 증거가 아님**. 따라서 실기기에서 계정 없이 이미 연결된 기기 간 승계 여부를 추가 확인해야 함.
- KMA 원본 시험지 25문항 순서, 별 보상 중복 방지, 연못의 체류 시간·자원 소모 조건은 그대로.
