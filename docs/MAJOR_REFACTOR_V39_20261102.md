## 2. 코드 구조

- `platform/numeric-keypad.js` **신규**: 순수 함수 기반 `normalizeNumericDraft`, `numericDraftReady`, `applyNumericKey`. 숫자 표기만 정규화하며 기존 정답 저장/채점은 여전히 `platform/activities.js` 담당. UI 드래프트는 저장하지 않음.
- `platform/activity-ui.js` 및 `village/village-ui.js`: 각자 구현하던 숫자판 로직을 공통 함수로 교체. 사용자 입력(음수, 0, 전각 숫자, 삭제) 경계값 일치.
- `platform/question-variety.js` **신규**: 문항 스토리/질문에서 숫자와 이름을 정규화해 표시 패턴을 추출. 편집용 휴리스틱이며 신규 문항 생성/답 수정/심리측정 모수 추정 **아님**.
- `platform/irt.js`: 같은 회차 내 패턴 반복에 최대 `3×0.34`, 최근 동일 게임의 패턴 노출에는 최대 `5×0.035`의 **낮은 선택 우선순위 패널티**. 정답 예측, 첫 독립 풀이만 추정, 가족 형제 데이터 분리, 공식 25문항 순서는 그대로.
- `village/village-ui.js`: 라운드 완료 직후 선택적 맞춤 3걸음, 2D 모드의 검증된 완료 트랜잭션, 목적지 보조 안내.
- `village/village-bridge.js`: 화면에 표시할 문항의 과목을 함께 제공하여 다음 배움 추천에 활용(정답·원본 메타데이터는 보내지 않음).
- `village/readability-v39.css` **신규**: 기존 v36/v37을 덮어쓰지 않고 마지막에 로드하는 접근성 보완 레이어.
- `scripts/check-refactor-v39.mjs`, `scripts/qa-refactor-v39.mjs` **신규**: 순수함수·IRT 변주·실제 2D 학습 완료·후속 학습 UI 회귀 테스트.

## 3. 보존 계약

1. 모든 `games/**`와 `games/irt-bank.json`, 뱁수 KMA 원본, 정답·원문·출처를 변경하지 않음.
2. `localStorage` 키, 기존 앱 백업 형식 및 병합 정책, 과목·별·물고기·정원·놀이 체류 자원, 프로필 키 `tae/se`는 변경하지 않음.
3. 클라우드 동기화 스키마·가족 연결·응답 원장·오프라인 재전송을 변경하지 않음. 기기 간 이어하기는 **기존에 연결된 기기에서만** 동작하며 이 업데이트가 자동 신규 연결을 제공하는 것은 아님.
4. IRT는 검증된 검사 모수가 아닌 잠정 문항 운영용 지표. 아동 발달/지능/학교 성적 판정으로 해석하지 않음.
5. 출제 선택·화면 표시만 변경하고 원본 KMA 시험지 순서 및 채점, 별 적립, 방문·돌봄 선행학습 조건을 변경하지 않음.

## 5. 남아 있는 작업·리스크

- **Unity 3D 건물 자체의 간판 텍스처**는 이번 패치에서 편집하지 않음. 큰 목적지 안내 자막으로 우회하되, 원화/Unity 씬 재컴파일·실기기 검증은 별도 게임 아트 작업으로 분리해야 함.
- 문항 텍스트 유사도는 간단한 규칙 기반 휴리스틱. 다양성 향상은 확인했지만 학습효과 개선을 입증한 연구 결과가 아님. 부모 관찰과 익명 집계 기반의 반복 노출/이탈 추이로 차후 평가해야 함.
- 모든 회귀 테스트 통과는 실기기 삼성 인터넷/모바일 Safari/Unity WebGL GPU 렌더 품질 보증과 동일하지 않음. 서비스 병합 전에 실제 태블릿으로 학습·연못·복귀·기기 동기화를 확인해야 함.
- 배포·기존 데이터 초기화·동기화 코드 재발급은 이 패치의 범위에서 제외.

### 롤백 방법

배포 후 문제가 발견되면 해당 커밋을 `git revert`하고 재배포. **저장 형식 변경이 없으므로** 과거 백업/동기화 키를 역이행하거나 원장을 삭제할 필요 없음. 단, 롤백 전에 현재 학습기록을 백업하고 기기별 서버 동기화 상태를 확인해야 함.
