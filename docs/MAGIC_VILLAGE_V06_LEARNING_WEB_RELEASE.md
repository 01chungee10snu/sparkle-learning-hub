# 태희·세희 마법마을 v0.6.0 웹 체험판 · 2026-10-10

## 1. 게임 경험
- Unity WebGL 3D/2.5D 마을은 기존 월드와 학습기록을 그대로 유지한다.
- 수학문제의 약 40%는 해시 기반 결정론적 분류로 공간 조작을 사용하며, 나머지는 마법책/두루마리/수정판의 읽기·선택 방식을 사용한다. 이 비율은 문제 수에 대한 코드상 선택 규칙으로, 실제 출제 결과의 비율을 매번 정확히 보장하지는 않는다.
- 조작형 문제는 선택형 마법문/수량 조절형 열매 바구니로 구성된다. 답안은 원본 질문 ID와 기존 Progress 채점기로 그대로 전송한다. 드래그 앤 드롭과 본격적인 월드 피직스 퍼즐은 후속 과제다.
- 원본 KMA 벡수 경시대회는 1번부터 25번까지 순서 고정, 학년·시험 난이도 선택, 원본 이미지/해설 유지한다. 소스의 라이선스 정책을 변경하지 않는다.
- 수학/국어/영어 4153개 색인 항목은 잠정 1PL + 추측 보정 IRT 모형에 따라 추천한다. 별도 단위 정원 48문항은 이 색인과 독립이다.

## 3. 캐릭터 8방향 원화의 품질 상태
- 고화질 기준 원화: `Assets/Art/Generated/Directional/fairies_turnaround_source.png` (태희·세희 × 4시점, 총 8 독립 소스).
- Canva에 생성된 8시점 시안: 태희 미디어 ID `MAHXnCslfsw`, 세희 미디어 ID `MAHXm96VFnA`. 시안 자체는 각각 1536×1024로 생성됐으나, 현재 Canva 커넥터는 200×133 미리보기만 다운로드 가능했다.
- 로컬 `EightView/tae_atlas.png`, `se_atlas.png`는 해당 200×133 JPG를 1536×1024로 확대한 **시각 테스트용 독립 포즈 프로토타입**이다. 출력 픽셀 크기만 커졌고 실제 시각 상세정보는 증가하지 않았다. 이를 최종 원화로 인식하지 않는다.
- 인게임 상단 `🎭 8방향 시안`에서 실험적 8포즈를 비교하고 `🎨 고화질 원화`로 되돌릴 수 있다. 기본 모드는 원래 고화질 4시점+사선 합성 방식이다.
- 진정한 최종 8방향 원화 확정에는 **Canva 생성 1536×1024 원본 2장을 투명 배경 PNG로 확보해 교체**하는 과정이 남았다. Canva 배경제거 기능은 해당 계정의 현 플랜에서 거절됨. 무리한 자동 다운로드/권한 우회나 구독 변경 없이 보류한다.
