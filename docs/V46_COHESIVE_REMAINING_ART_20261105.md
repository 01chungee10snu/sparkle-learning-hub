# 마법마을 v46 — 남은 캐릭터·도감·보상·공통 화면의 시각 통합

작성·검증일: 2026-11-05. 기준 운영본은 v45 `50874ed84c752b89ae03ecdba3753e2570f36ef7`이다. 사용자의 ‘나머지도 모두 수정’ 요청을 기존 활동·기록·정답 권한을 유지하면서 남은 시각 자산과 화면을 통합하는 작업으로 해석했다.

## 결과와 구현 경계

이번에는 새 콘셉트 이미지를 보여주거나 마을 배경만 교체하지 않았다. Blender로 실제 모델을 제작하고 Unity 게임의 요정·NPC·연못 생물에 연결했다. 도감·직업·선물·보호자 및 기록 화면은 같은 모델의 직접 렌더링 이미지와 읽기 쉬운 실시간 글자를 사용한다.

| 대상 | 실제 변경 | 보존 |
|---|---|---|
| 태희·세희 요정 | Frakassets/Pixor의 공개 CC0 Fairy 원본을 수정한 분홍·연보라 3D 모델. 몸·머리·양팔·양다리·양날개를 분리하고 이동 방향·인사·학습 동작을 기존 명령에 연결 | 학습자 ID·이동·착용 상태·기존 원본 파일 |

직업 표현은 임금순으로 크기·지위를 강조하지 않고 동일한 크기의 전시대를 사용했다. 생물 모델은 어린이용 양식화 표현이며 생물학적 식별 도판은 아니다. 경시대회 원본 그림, 문제의 문자·기호·수량·정답, 저장된 설명을 임의로 다시 그리거나 바꾸지 않았다. 작은 글자까지 메시로 만들지 않았으며, 접근 가능한 텍스트·입력은 기존 웹 구조를 유지했다.

## 제작물·성능

제작·편집한 모델 및 모델별 렌더 272종(두 요정은 공개 Pixor Fairy 원본 기반): 캐릭터/도우미 11, 생물 64, 직업 100, 선물 48, UI·성장/보상 아이콘 43, 꽃 장식 6. 전체 배치와 입장용 장면 렌더 2장도 현재 Unity 모델로 갱신했다. 현재 쓰는 기본 마을의 각 배우 수는 별도 실행 증거로 기록하며, 제작한 모든 예비 캐릭터가 동시에 배치되는 것은 아니다.

직업·선물 모델은 오프라인 렌더용 카탈로그에 두고 모바일 게임의 Resources에 전부 넣지 않았다. 런타임에는 실제 사용하는 캐릭터·수집 생물·일부 보상/장식 모델만 포함한다. 웹 실행 파일 네 개 합계는 26,584,810 → 30,493,007바이트, 3,908,197바이트(약 14.70%) 증가했다. 이 수치는 전송 파일 크기이며 RAM·실측 FPS가 아니다. 도감은 페이지 단위 및 지연 이미지 로딩을 유지한다.

새 요정은 기존 평면 그림의 정밀 3D 복원이 아니라, 공개 CC0 Fairy 모델을 편집해 분홍·연보라 정체성을 유지한 디자인이다. 공개 모델 후보·제작사 라이선스·원본/변형 해시는 V46_PUBLIC_FAIRIES_AND_MOBILE_CENTER_20261105.md와 public-fairy-provenance.json에 기록했다. 모든 뼈대가 있는 스킨 애니메이션으로 바꾼 것이 아니라, 명명된 Blender 메시 부품의 피벗을 Unity에서 제어한다. 기존 원화와 가벼운 모드는 삭제하지 않고 장애 시 이미지 대체 경로를 남겼다.

## 보존·재현·검증 한계

89개 보호 대상 파일을 v45 운영본과 바이트 단위로 대조했다. `games/`, `supabase/`, 진도·IRT·보상·재화·동기화·연못 시간·놀이 균형·직업 수치/설명·관계/정원 상태·선물 카탈로그 등을 변경하지 않았다. 실제 가족 데이터를 읽거나 시험 답안으로 덮어쓰지 않았으며, 브라우저 검사에서는 운영 Supabase 요청을 차단했다.

Blender 편집 원본, FBX, Unity 프리팹/C#은 비공개 Unity 저장소의 `feat/cohesive-world-v46-20261105`에 보존한다. 공개 웹에는 실행본·직접 렌더·제작 스크립트·검증 기록만 포함한다. 기존 라이선스 선택은 변경하지 않았다. 원본 사용자 참고 이미지를 배포 자산으로 복제하지 않았다.

검수 중 캐릭터 정면 방향, 성장 단계별 그림 구분, 파일 수 변화에 따른 검사 계약, 최초 마을 상태의 테스트 대기조건을 수정했다. 이 수정은 정답이나 보상 규칙 변경이 아니다.

**한계:** 물리적 갤럭시/iPad·Safari·발열·메모리·실측 FPS는 검사하지 않았다. 검사 환경은 Chromium 터치 에뮬레이션/소프트웨어 WebGL이다. 가족 기록 병합은 모의 RPC이며 운영 클라우드의 실제 사용자 데이터를 사용하는 실험은 하지 않았다. 생물 표현은 양식화된 게임 아트이며 과학적 식별 도판이 아니다.

재현:

```sh
blender -b --factory-startup --python-exit-code 1 --python unity-v46/export_cohesive.py -- /path/to/unity-v46
blender -b --factory-startup --python-exit-code 1 --python unity-v46/export_gifts.py -- /path/to/unity-v46
# Unity batch entry: VillageCohesiveBuild.PrepareAndBuild; optional RenderOverview
python3 scripts/sync-cohesive-v46.py /path/to/unity-v46
npm run check
COHESIVE_QA_ORIGIN=http://127.0.0.1:4666 npm run qa:cohesive:v46
INTERIOR_QA_ORIGIN=http://127.0.0.1:4666 npm run qa:interiors:v45
```

최종 공개 주소/실행 파일 해시/배포 후 브라우저 검증은 `qa-cohesive-v46/deployment.json`에 별도 기록한다. 해당 확인 전에는 운영 배포를 완료로 해석하지 않는다.
