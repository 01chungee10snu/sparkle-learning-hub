# 마법마을 Ocean v25 · 2026-10-19

## 어린이 동선

- 웹 루트 `/`는 **태희 / 세희** 중 한 명을 선택한 후 **마을 입장 / 학습페이지 입장**만 제공합니다.
- 마을은 `/village/?who=tae|se&autostart=1`을 통해 선택된 캐릭터를 3D로 바로 입장시키며, 잘못된 파라미터는 삭제합니다.
- 학습은 `/learning.html?who=tae|se`로 바로 들어가고 아이별 기존 기록(학습·별·자원)을 유지합니다.
- 직접 `/village/`에 방문할 때는 보호자와 아이를 다시 고를 수 있는 안전한 진입 화면을 유지합니다.

## 연못·바다

연못 6종: 구피·금붕어·네온 테트라·베타·잉어·엔젤피시.

바다 10종: 흰동가리·블루탱·새우·소라게·바다 게·해마·문어·바다거북·산호초 상어·혹등고래.

각 생물은 개별 **1536×1152 투명 SVG 원본**을 가지며 `VectorCraft`에서 내보낸 **WebP 자산**으로 화면에 표시됩니다. 외부 스톡 이미지, 저작권 불명 원화, 이모지 대체는 쓰지 않았습니다. 관련 파일 `village/assets/marine-premium-v25/`.

해금 요구사항은 새롭게 해결한 서로 다른 문제 수(`minSolved`), 과목별 획득 자원(수학 수정·국어 꽃잎·영어 깃털·한자 먹방울), 세 과목 이상을 같은 날 학습한 균형일(`minBalancedDays`)입니다. 바다의 생물 등급이 올라갈수록 세 요구치가 비감소하며, 신규 문제 수·총 비용은 엄격하게 증가합니다. 정답 반복 노가다로 별·자원을 무한 생성할 수 없도록 기존 중복 방지 정책을 유지했습니다.

매일 먹이와 관찰 기록은 하루 한 번만 추가되며 돌봄을 놓쳤다고 사라지거나 벌점이 발생하지 않습니다. 고래·상어·바다거북은 실제 사육 대상으로 제시하지 않고 **야생 동물을 가상 해양 보호구역에서 멀리서 관찰**하도록 구성했습니다.

## QA와 사실 관계

- `npm run check`: 통과 (기존 학습·IRT·한자·직업 100종·화폐·원화 회귀)
- `node scripts/check-ocean-v25.mjs`: 통과 (연못 6·바다 10, 정렬·해금·원화 실물, 라우팅)
- `scripts/qa-intro-career-v26.mjs`: 데스크톱 1440×900, Galaxy 390×844, 태블릿 768×1024 **3/3 통과**, 자바스크립트 예외 0건. 테스트 스크린샷 `docs/qa-ocean-v25/` (운영 저장소에는 민감하지 않은 합성 테스트 결과만 보존 가능).

**구현 범위:** 바다는 2.5D 인터랙티브 해양생물 도감과, Unity 6000.3.26f1에서 별도로 빌드한 실제 3D 남쪽 해변·부두·관찰 데크·산호초·해양생물 3D 환경을 제공합니다. 기존 섬 전체 이동 범위를 무제한 넓힌 것은 아니며, 해변에서 관찰 장소까지 보행 가능한 구간을 추가한 것입니다. `VillageMarineCoastAudit.Verify`의 `MARINE_COAST_AUDIT_OK`와 `MAGIC_VILLAGE_WEB_BUILD_OK` 확인. Unity 소스 패치는 격리된 `/ai-interop/runtime/magic-village-unity-ocean-worker3-20261019/worker3-unity-ocean.patch`에 보존했습니다. 신규 WebGL 빌드에 대한 `scripts/qa-unity-ocean-v25.mjs` 실제 Chrome WebGL 기동검사 **데스크톱/Galaxy 화면 크기 2/2 PASS, 콘솔 오류 0건** 확인했습니다. 이 검사는 휴대전화 실기기 QA가 아니라 Chrome 브라우저의 모의 화면 크기 검사입니다.

**원화 품질:** 제공 자산은 자체 제작한 편집 가능한 일러스트레이션입니다. 외부 유료 고급 이미지 서비스 접근이 거부되어 외부 스톡·Firefly 비용은 발생하지 않았습니다. 사용자가 요구한 최상급 렌더/원화의 미감 승인은 별도 크리에이티브 QA 및 사용 권한 확보 후 재평가해야 합니다.
