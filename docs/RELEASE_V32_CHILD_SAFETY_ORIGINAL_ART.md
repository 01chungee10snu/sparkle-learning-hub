# 마법마을 v32 — 아동 언어·원화 정밀 개선 보고

2026-10-19. 기준: 공개 저장소의 첫 방문·해양생물 64종 v30 작업본 `a5c008c`에서 분기한 독립 기능 브랜치.

## 1. 아동에게 표시하는 표현

학습 효과를 인정하면서도 **점수·순위·소득을 아이의 가치나 능력과 동일시하지 않는다**는 원칙으로 개정했다. 주요 화면은 세희(유아·그림/듣기 중심)와 태희(초등 저학년·읽기/자기설명)를 구분한다.

| 수정 영역 | 기존 표현·위험 | 새 화면의 의도 |
|---|---|---|
| 해양생물 | `해금`, `보유`, `영입`, `자원 부족` 등 거래형 용어 | `만난 친구`, `새로 만날 친구`, `배움 재료`, `다른 곳도 둘러봐요` |
| 고래·상어·바다거북 | 집에서 키우거나 만지는 것으로 오인할 수 있는 문구 | 야생 보호구역에서 **안전한 거리로 관찰**하는 표현 |
| 경시대회·연습 | `완주 특별 보너스 +n별`, `내 수준`, `심화 난도` | 25문항을 나누어 풀고, 쉬어 가며 만나는 경험. 보상 원장은 보존 |
| 학습 직후 | 첫 선택 정답 `n/m` 표시, `오답`, `최고 단계 달성`, `Lv.` | 다시 생각한 방법, 발견, 지금의 마을 모습. 정밀 수치는 보호자 학습 기록으로 |
| 말로 설명하기 | 설명 대가로 `+2별`, 하루 보상 상한 강조 | 이야기하고 싶을 때 말하기. 설명을 점수로 평가하지 않음. 기존 별 기록 보존 |
| 직업 도감 | 연봉/입결/합격률에 따른 직업 우열로 읽힐 위험 | 모든 직업의 가치와 사회적 역할 강조, OECD·연봉·입시 통계는 **보호자 참고**라고 명시. 수치·출처 자체는 변경하지 않음 |
| 이동·상단 알림 | 연못 버튼이 숨은 메뉴에만 있고 한국 시간 휘장이 손가락 입력을 가림 | 연못·바다를 직접 열 수 있게 배치, 시각 정보 오버레이 터치 간섭 제거 |

### 표현을 바꾸면서도 유지한 기능

- IRT 난이도 개인화, 66개 게임/8,462개 문제, 수학·국어·영어·한자별 학습 자원, 일회성 장소 방문 보너스, 별 포인트·학습 성취 기록을 그대로 유지했다.
- 임의의 정답을 새로 만들거나 공개 시험의 원문 정답을 고치지 않았다. 초기에 골랐던 답의 정확성은 보호자 기록에서 확인할 수 있다.
- 실제 노동시장의 연봉/직무/학업 진입 요건, 원자료 출처와 계산식은 직업 도감의 보호자용 근거 자료에 보존했다.

## 2. 학습 콘텐츠 언어 교정

- 66개 게임·8,462개 문항, 71개 관련 파일 중 42,923개의 직접 작성된 사용자 노출 문자열을 패턴 감사했다.
- 한자 설명문 2,084개에서 받침에 맞지 않는 종결어미를 교정했다. 예: `‘소 축’예요` → `‘소 축’이에요`.
- **정답·보기·문항 ID·상호작용 채점 규칙·원본 수학 그림·출처·IRT 모수 불변**을 별도 `scripts/check-question-integrity-v32.mjs` 및 `docs/CHILD_COPY_QUESTION_INTEGRITY_V32.json`으로 고정했다. 업데이트된 `games/irt-bank.json`에는 텍스트 원본 `sourceSha256`만 반영했다.
- 표준 한자 훈음이나 원본 시험문항은 의미를 왜곡하지 않도록 유지했으며, 어린 연령에는 그림·설명 도움을 우선한다.
- 자동 문자열 검사만으로 맥락 전체를 검증했다고 보지 않는다. 언어와 발달 적합성은 보호자/아이 실사용 관찰이 필요하다.

## 3. 원화·게임 그래픽

- 연못24 + 바다40 = 64종의 **원본 SVG 64개·투명 WebP 64개**. 모든 소스를 독립 보관, VectorCraft로 1536×1152 투명 렌더링, 64개 모두 개별 이미지 디코딩·고유 SHA·불필요 배경/크롭 영역 침범 검증.
- 일반 64종에서 그라디언트·반사광·비늘/지느러미 광택·곡선 광원을 개선하고, 불충분한 실루엣 6종(대왕오징어, 대왕쥐가오리, 만다린피시, 긴주둥이나비고기, 아메리카바닷가재, 장수거북)을 독립 bespoke 원화로 다시 제작했다. 재현 가능한 `scripts/upgrade-marine-art-v32.py` 및 `scripts/marine_bespoke_v32.py` 제공.
- 직업 100종 원화 중 직업 도구의 이모지에 의존하던 12종(의사·치과의사·비행기조종사·수의사·로봇·AI·건축·게임디자이너 등)을 **벡터 소도구**로 교체했다. 나머지 88종의 폰트 의존형 소도구는 후속 교체 대상으로 문서화했다.
- 클릭 가능한 한자 학습관에 필요한 `village/assets/illustrations/hanja-icon.webp` 누락(404)을 발견하여, 붓과 두루마리가 있는 별도 편집 가능한 SVG + WebP 원화를 신규 제작했다.
- 현재 품질은 아동용 **2.5D 벡터 일러스트**다. 고화질 인쇄용 채색 원화나 완전한 3D 조형으로 과대 설명하지 않는다. 인체/동물 해부학·원화 미감의 최종 승인은 별도다.

## 5. 안전·저작권·남은 검증

- 원본 KMA 문제 중 `provenance.originalLicenseStatus='private_reference_only'`라는 자료 표기와 게임 내 공개 노출의 불일치가 확인됐다. v32에서 원본 문제/답·스캔을 새로 만들거나 바꾸지 않았고, 문구에서 공개 재사용 권한을 단정하는 표현은 제거했다. **실제 공용 서비스에서 스캔 원화를 계속 제공할 권리가 있는지는 별도 확인해야 한다.**
- 한자 데이터의 `rights='review_before_public_release'`는 원자료 활용 권리 검토 지시로 취급한다. 설명문 교정이 원자료 사용 허가를 의미하지 않는다.
- 이전 프로젝트 문서 일부가 4,876개 문항이라고 쓰여 현재의 8,462개 실제 데이터와 다르다. 이번 QA는 현재 카탈로그/IRT 은행을 기준으로 수행했다.
- 다른 격리 작업본의 아직 커밋되지 않은 수정 사항은 건드리지 않았다. 릴리스는 변경 브랜치의 정확한 SHA·기존 운영 main의 최신 변경을 재확인한 뒤 수행한다.
