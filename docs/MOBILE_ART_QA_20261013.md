# 통합 마법마을: 모바일·태블릿 UX와 원화 적용 QA (2026-10-13)

## 적용 범위

- 기준 소스: GitHub Pages `sparkle-learning-hub`, Unity v0.8.0 통합 마법마을의 HTML UI 계층
- 변경: `village/mobile-art-polish.css`, `village/village-ui.js`, `village/index.html`
- 학습·채점·IRT·기기 내 별/기록 저장 로직 및 Unity WebGL 바이너리는 변경하지 않음

## 상단 바 제거 추가 개선 (2026-10-13)

- 외부 상단 제목/학습기록 헤더를 DOM과 CSS에서 제거하여 Unity/2D 장면이 safe area를 제외한 화면 높이 전체를 활용하도록 변경.
- 모바일 HUD는 좌상단의 작은 이름·별 카드로 축소. 게임 중 기록 조회는 `더 놀기 → 학습기록`, 게임 입장 전에는 시작 카드 하단 링크로 제공.
- 화면 7종에서 캔버스 전체 높이, 버튼 간 겹침, 작은 터치 타깃, 가로 넘침을 검증하고 학습기록 링크의 실제 탐색을 자동 확인.

## 사용성 개선

1. 휴대전화 세로: 요약형 HUD, 학습 지역 이미지 칩, 탐험 바로가기 및 하단 메뉴가 **겹치지 않도록** 배치. 큰 터치 버튼을 유지하고 학습 모달은 내부 스크롤.
2. 가로 휴대전화: 학습 지역·기본 메뉴를 동일 하단 한 줄에 병렬 배치. HUD에서 장식·성장 상세 정보를 숨겨 실제 마을 면적 확보.
3. 태블릿: 기존 레이아웃을 유지하면서 학습 지역 선택기·아트 배너·터치 입력의 여백과 폰트 조정.
4. 갤럭시 숫자 입력: 운영 체제 키보드가 열리지 않아도 입력 가능한 기존 DOM 숫자 키패드와 정답 제출 버튼을 그대로 사용. 2D 모드에서 실제 수학 25문항의 세 번째 정수 입력 문제까지 브라우저 재현 검증.
5. 실험용 '8방향 시안' 전환 메뉴는 어린이에게 표시하지 않음. 경시대회/연습장 고학년 문제 선택 시 세희에게 보호자 동반 안내와 유아·기초 수학 모험 연결을 제공함.
6. 진입 시 **3D 마법마을 / 가벼운 2D 마을**을 선택할 수 있음. 2D 모드의 학습 지역, 채점, 보상·정원 데이터는 3D와 동일한 호스트 엔진을 사용하며, 별도의 WebGL 다운로드를 요구하지 않음. 2D 모드에서는 이동·달리기·날기 조작을 숨김.

## 원화 (사용자 소유 기존 Unity 원화 재활용)

`scripts/compose_village_art.py`가 `Assets/Resources/Sprites`에 있던 독립 RGBA 원본을 조합하여 웹 UI용 고화질 WebP 20종을 재현 가능하게 생성.

| 구성 | 수량 | 예시 |
|---|---:|---|
| 지역별 스토리북 그림 | 9 | 수학, 국어, 영어, 경시, 연습, 마법학교, 성장, 정원, 상점 |
| 지역 이미지 아이콘 | 9 | 마법학교, 도서관, 나무·꽃, 성 등 |
| 랜딩 가로형 환영 삽화 | 1 | 분홍 태희·연보라 세희와 기존 건물·꽃 |
| 2D 경량 모드 세로형 삽화 | 1 | 모바일 전체 높이에 맞춘 요정·건물 장면 |
| **합계** | **20** | 전체 약 935KB |

- 한글과 수치 등 정보 텍스트를 아트 파일에 굽지 않고 DOM 텍스트로 렌더링한다. 텍스트 가독성, 화면 회전, 접근성을 보호한다.
- 그림은 **기존 원화를 고해상도로 재구성·최적화**한 것으로, 독립적으로 새로 그려진 20개의 원화라고 표시하지 않는다. Unity 에셋 출처는 변함없다.
- 아래 생성 명령은 통합 Unity 레포에서 원본 파일을 읽는다. 원본이 없는 기기에서는 **기존 커밋의 완성된 WebP 에셋으로 정상 실행된다**.

```bash
python3 scripts/compose_village_art.py
npm run check
npm run qa:mobile
npm run qa:lite
npm run qa:unified
```

## 실기기 점검 시나리오

1. Galaxy Chrome과 삼성 인터넷에서 공개 URL을 열어 태희/세희 선택, 3D 모드의 조작·진입·로딩 시간 확인.
2. 모바일 **세로/가로** 회전 후 모든 지역·하단 메뉴 버튼이 눌리는지 확인.
3. 25문항 경시대회/연습장의 숫자 답 입력: 키패드 입력·한 자리 지우기·전체 지우기·정답 확인·다음 문제 이동.
4. 2D 모드에서 수학·국어·영어·정원·상점 접근 및 브라우저 저장 기록 재진입 유지.
5. 한 문제를 여러 번 틀렸을 때 별이 차감되지 않는지, 25문항 중단 후 다시 이어 풀 수 있는지, 기록이 자매 사이에 섞이지 않는지 확인.
6. 3D 발열 또는 메모리 종료 여부를 15~20분 플레이로 평가. 성능이 낮으면 2D 모드를 선택하도록 안내.
7. 실제 어린이 관찰: 그림이 더 풍부해졌는지, 메뉴를 찾느라 탐험이 중단되는지, 경시대회 난도를 선택할 때 부담감이 있는지 기록. **별의 개수를 학습능력 평가로 해석하지 않음.**

## 보류·한계

- 실제 모바일 기기에서의 GPU 성능, 삼성 인터넷 브라우저 호환성, 제스처 감도는 미검증.
- Unity 3D 월드의 3D 메쉬를 새로 모델링하거나 WebGL 바이너리를 변경하지 않았다. 고급 원화는 웹 랜딩/2D 장면/학습 지역에 추가로 적용한 것이다.
- 처음 연결하는 기기의 저장 데이터는 자동 동기화되지 않는다. 기록은 브라우저·기기별로 관리하며 내보내기/가져오기로 이전한다.
