# 마법마을 v17 — 동물 친구와 가족 기기 연결

## 시작하기

마법마을에 들어가 **꾸미기 → 동물 집**에서 토끼와 햄스터를 초대합니다. 3D 마을에서는 저장된 친구가 실제 마을 지형에 나타납니다. 동물 집의 **마을에서 산책**, **나를 따라와**, **잠깐 쉬기**로 행동을 바꿀 수 있습니다. 물고기 연못에서 초대한 금붕어와 구피는 연못 안에서 헤엄칩니다. 메뉴를 열거나 문제를 풀 때에는 마을 동물의 이동이 잠시 멈춥니다.

기기 두 대를 연결하려면 첫 기기에서 **설정 → 가족 기기 연결 → 새 가족 만들기 → 코드 복사**를 선택합니다. 다른 기기의 같은 웹페이지에서 **설정 → 가족 기기 연결**을 열어 코드를 붙여넣고 **기존 가족 연결**을 선택합니다. 연결은 한 번만 설정하며, 이후 변경사항은 자동으로 전송됩니다. 연결 코드는 가족에게만 공유해야 합니다. 브라우저 저장공간을 삭제하거나 시크릿 모드를 종료하면 해당 기기는 다시 연결해야 합니다.

## 저장되는 내용

태희·세희의 문제풀이 기록과 진행 중인 회차, 별 지갑, 기존 나무·꽃 정원, 개인 텃밭·물고기·반려동물, 가족 광장, 가족 설정 및 요정 스타일을 동기화합니다. 현재 선택한 어린이는 기기마다 유지합니다. 동물이 걷는 좌표는 각 기기에서 계산하며, 다른 기기의 동물이 같은 프레임에 같은 위치에 있는 실시간 멀티플레이 방식은 아닙니다.

연결 전에는 해당 기기에만 저장됩니다. 연결된 상태에서 통신이 끊겨도 이미 불러온 마을의 돌봄 기록은 기기에 남고, 연결이 돌아오면 다시 전송합니다. 앱 전체의 최초 로딩이나 모든 문제 이미지가 인터넷 없이 제공된다는 의미는 아닙니다.

## 충돌과 개인정보

두 기기에서 같은 개인 마을을 동시에 다르게 바꾸면 자동 덮어쓰기를 멈춥니다. 화면에서 유지할 마을을 고르며, 학습·보상 기록은 기존 검증 규칙에 따라 병합합니다. 충돌 직전 양쪽 스냅샷은 해당 기기에 암호화해 보관합니다.

가족 기록은 기기에서 AES-GCM으로 암호화됩니다. 서버에는 암호문과 버전·인증 검증용 해시를 저장하며, 연결 코드 자체는 전송하지 않습니다. 연결 코드는 해당 기기의 브라우저에 저장되므로 기기를 다른 사람에게 넘길 때에는 **연결 해제**를 사용합니다. 연결 해제는 해당 기기의 연결을 끊으며 서버 기록을 삭제하는 동작은 아닙니다.

## 구현 범위

Unity WebGL 0.17.0, 기존 원화 기반 토끼, 종별 3D 메시 햄스터·물고기, 실제 지형 경로 및 연못 경계 검사를 사용합니다. 가족 공유 서버는 마법마을 전용 Supabase 프로젝트이며, 별도 과금 결제나 계정 비밀번호 입력 없이 가족 코드로 연결합니다. 서버 접근이 불가능할 때 화면은 동기화 완료로 표시하지 않습니다.
