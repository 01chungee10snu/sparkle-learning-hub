# 마법마을 가독성·IRT 적응형 출제 개편 v37

기준: 2026-10-31 · 대상: 태희/세희의 통합 반짝 배움터 · 기준 브랜치: `main` v36

## 사용자 문제가 발생한 이유

- 학습 3~5문제의 ID가 회차 시작 때 모두 정해져 연속 정답을 맞혀도 중간에 더 어려운 문제가 출제되지 않음
- 성장 단계별 문항이 8개에 불과하고, 저자 지정 b 범위가 좁아 같은 수준 안에서는 상향 체감이 약함
- 활동 추천이 같은 과목과 동일한 문제 형식을 우선하여 학습 형식 변화가 적음
- 직업사전 카드의 2줄 말줄임, 한자 플래시카드 12px, 연못 첫 방문 보상 팝업에 따른 조작 영역 가림

## 변경한 적응형 출제 규칙

1. 독립적인 최초 응답만 잠정 IRT 능력(`theta`) 및 연속 정답의 근거로 사용. 힌트 제공 응답과 동일 문항의 반복 제출은 능력 상향에 포함하지 않음
2. 2/4/7회의 연속 독립 정답이 쌓이면 목표 정답 가능성을 점진적으로 낮춰 더 까다로운 문항을 탐색. 반대로 최근 오답에서는 난이도를 완화
3. 응답할 때마다 같은 회차에서 **아직 제시하지 않은** 문항만 재선정. 풀고 제출한 문항, 정답, 보상, 기록은 불변
4. 서로 다른 개념·응답 형식(선택/배열/짝맞추기/숫자 등)과 미출제 문항을 선호하고, 반복 노출된 문항 패밀리 및 유형에 패널티 부여
5. 독립적 정답 증거가 충분할 때만 탐험형 활동에서 바로 위 **한 단계** 문제를 가이드 도전으로 노출. 선택 단계·학년 자동 변경이나 공식 진단은 하지 않음
6. 시험지 25문항은 원문·원순서 유지. 간격 반복 복습 회차도 복습 대상과 출제 순서를 유지

## UI 교정 내용

- 휴대전화/태블릿의 원화와 내용은 유지하면서 제목·설명·보상 정보를 14px 안팎 이상으로 확장
- 한자 플래시카드 및 직업사전 카드의 중요 설명 글씨 확대, 직업사전의 2줄 잘림 제거 및 좁은 화면에서 가로 일러스트·텍스트 배치
- 연못 첫 방문 보상은 모달의 본문 흐름으로 이동. 기존의 조작 버튼 위 팝업을 제거
- 매우 낮은 가로 화면(667×375, 844×390)에서는 3열 정답 보기, 패널 여백 축소 및 푸터 높이를 정합시켜 정답을 화면 내 표시
- 화면보다 긴 상세 목록과 해설은 작은 글씨로 축소하지 않고 내부 세로 스크롤 허용

## 검증

- Chrome 화면 에뮬레이션 9종 (280×653, 320×568, 360×740, 390×844, 430×932, 768×1024, 1024×768, 844×390, 667×375)
- 화면 그룹 11종 (진입·학습·수학 문제집·한자·성장·별 선물·마을 입장·마을 탐색·연못·바다·직업사전)
- 초기 전수 스캔 99개 조합에서 직업사전 보조 문장 잘림 34건 발견; 수정 후 **잘림 0건**
- `npm run qa:readable:v37` 에서 9개 화면의 레이아웃·핵심 버튼·한자/직업 글씨·연못 안내를 직접 검증
- `npm run check:adaptive` 로 연속 정답·오답, 실제 5문제 사이의 변경, 컨텐츠 다양화, 보호자 단계 불변, 학습기록·25문항 시험지 보존을 확인
- 전체 검증 `npm run check`, 기존 모바일·연못 및 어린이 UX 테스트 결과를 별도 점검

## 과학적·운영상 한계

- 현재 b 및 c는 콘텐츠에 부여한 초기/잠정 값. 충분한 학습자 응답을 통한 IRT 모수 보정이 이루어지지 않아 검사·능력 진단·교육적 선별에 사용하면 안 됨
- 문제은행에 상위 난이도가 없는 경우 무제한 자동 상향은 불가능. 이때는 **다른 개념·풀이·맥락**으로 확장하거나 보호자가 다음 단계를 선택해야 함
- 실제 Galaxy·iPad 물리 기기와 Safari 실기기 상호작용은 별도 QA가 필요하며 본 검증은 Chrome 에뮬레이션
- 태희·세희의 실제 학습 기록을 건드리지 않고 합성 테스트 프로필 및 브라우저 격리 컨텍스트로 검증
