# 직업사전 v29 · 전체 화면·어린이 친숙도·직업별 일러스트

작성일: 2026-10-19

## 구현 범위

- 마법마을 직업 탐색관 전용 화면을 **뷰포트 전체 높이·폭**으로 열고, 100개 직업을 스크롤 가능한 전체 화면 목록으로 표시. 타 학습관의 대화창 크기는 변경하지 않음.
- 기본 정렬은 어린이 주변에서 자주 만나거나 그림책에서 접하는 직업(초등학교교사, 유치원교사, 보육교사, 의사, 수의사 등)을 우선 표시. **직업의 사회적 가치·학업 성취도·임금 우열을 의미하지 않음**. 연봉 중앙값 높/낮은 순, 가나다순, 분야별, 내 꿈 후보 우선 정렬 선택 가능.
- 100개 직업에 별도의 독립 SVG **인물·의상·직업 도구 일러스트**를 생성해 카드와 상세 화면에 표시. 원본 생성기 `scripts/build-career-art-v29.py`, 이미지 감사 목록 `village/assets/career-illustrations/manifest.json`. 저작권 미확인 외부 이미지 미사용.
- 미해금 직업의 얼굴·이름·하는 일·기여·준비할 공부·어린이 미션·공식 출처는 공개 유지. **연봉·시간당 환산·학력/입결/시험의 숫자 정보만 잠금**. 별도 공개 수치가 없을 때 가상 석차를 만들지 않음.
- 기존 두 과목 학습화폐 각 1개로 영구 해금, 개인별 내 꿈 기록, 공식 통계자료의 조사연도·중앙값/평균값 구분은 유지.
- 모바일에서는 분야 칩을 한 줄로 가로 이동하고, OECD 집단 통계 안내는 사용자가 펼쳐 볼 수 있도록 구성해 직업 카드 접근을 앞당김.

## 제한

- 일러스트는 일관된 독자 SVG 스타일의 초기 완성본입니다. 사진·외부 유료 이미지 라이선스나 사람 얼굴을 무단 사용하지 않았습니다. 시각적 다양성은 직업 의상·도구·배경의 조합으로 구성되어 있으며, 향후 실제 일러스트레이터 원화로 교체할 수 있습니다.
