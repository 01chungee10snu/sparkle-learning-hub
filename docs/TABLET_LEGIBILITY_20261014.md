# 태블릿 글씨·문제창 개선 (2026-10-14)

## 요청과 구현

태희·세희의 통합 마법마을을 태블릿에서 조작할 때 글씨가 작은 문제를 해결하기 위해, 태블릿 화면(가로·세로 CSS 뷰포트 너비 600~1500px, 높이 600px 이상)에 별도 스타일을 적용했습니다. 기존 Unity 3D/경량 2D 학습 엔진, IRT·정답 검증·학습기록·별 보상은 변경하지 않았습니다.

| 실제 CSS 요소 | 기존 | 변경 |
|---|---:|---:|
| 25문항 이야기 본문 | 14px | 21px |
| 25문항 질문 | 18~24px | 26px |
| 선택형 버튼 | 20px | 23px |
| 학습 지역 과제명 | 17px | 22px |
| 학습 지역 설명 | 13px | 18px |
| 학습 지역 바로가기 | 14px | 18px |
| 메뉴 및 기본 이동 | 14px | 18px |
| 풀이 해설 | 16px | 21px |
| 원본 문제집 선택 | 16px | 21px |
| 숫자 답 입력 | 24~31px | 35px |

- **태블릿 모달:** 이전 가로폭 650~1000px 제한을 제거하고 좌우 바깥 여백을 약 4~8px로 줄였습니다. 상하 여백도 최대한 줄이고 제목·문제·설명·답변 및 하단 고정 조작 버튼을 유지합니다.
- **세로 배치:** 긴 문제에 대해서는 모달 내부 콘텐츠만 세로 스크롤합니다. 원본 문제 그림을 더 크게 볼 수 있는 공간을 확보했습니다.
- **문제지:** 원본 이미지가 없는 25문항은 좌측 빈 책장이 화면을 낭비하지 않도록 단일 흐름으로 바꿨습니다. 원본 스캔이 있는 경우에는 문제 이미지·답변을 구분해 표시합니다.
- **화면 밖 UI:** 지역 메뉴, 아이별 상태, 별 정보, 정원·선물 버튼, 학습 종료/읽어주기/힌트 버튼까지 확대했습니다.
- **휴대전화:** 화면 높이 600px 미만(일반 휴대전화 가로 등)에는 별도 변경을 최소화해 기존 모바일 회귀를 방지합니다.
- **아동 개인정보/학습기록:** 저장 구조, 동기화·별 지급 규칙, 원본 자료는 변경하지 않았습니다.

## 검증

재현 가능한 명령:

```sh
npm run check
npm run qa:tablet
npm run qa:mobile
npm run qa:lite
npm run qa:unified
npm run qa:hotspot
```

태블릿 자동 QA는 768×1024, 1024×768, 800×1280, 1280×800, 600×960 CSS 픽셀 화면에서 학습 지역·질문·25문항·숫자 입력·피드백을 검증합니다. 글자 크기, 화면 가로 넘침, 최소 터치 타깃 42px, 작은 화면에서의 내부 스크롤, 레이아웃과 상호작용을 확인하며 캡처와 JSON을 남깁니다.
