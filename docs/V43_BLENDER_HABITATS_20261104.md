# 마법마을 v43 — Blender 환경 요소와 움직임 확장

작성·검증일: 2026-11-04. **Unity의 실제 플레이 공간에 적용한 개발 버전이다. 운영 main/GitHub Pages 배포는 수행하지 않았다.**

## 1. 변경 결과

기존 v42의 Blender 기반 Unity 자산 39종을 유지하고, **새 환경 자산 18종을 추가해 전체 카탈로그를 57종으로 확장**했다. 웹 입장 화면의 미리보기만 바꾼 것이 아니라 Unity가 직접 렌더링하는 FBX·Prefab 및 움직이는 부품을 추가했다.

| 장소·범주 | 추가한 Blender 요소 | 실제 동작 범위 |
|---|---|---|
| 연못·물가 | 갈대, 연꽃과 잎, 작은 배, 나무 부두, 물결 링 | 수초의 흔들림, 연꽃·배의 미세한 부유, 물결의 크기 변화 |
| 폭포 주변 | 별도 물레방아 바퀴, 입체 물줄기 | 바퀴 회전과 물줄기 폭의 잔잔한 변화 |
| 정원·초원 | 유리 온실, 꽃 아치, 열매나무, 버섯 의자, 정원 디딤길 | 기존 자유 탐험 동선에서 볼 수 있는 공간 장식 |
| 풍차 | 풍차 본체, 별도 회전 날개 | 건물 전체가 아니라 날개 부품만 회전 |
| 해안·마법 장식 | 층진 해안 바위, 수정 군집, 매달린 등불, 분리된 나비 날개 | 등불 흔들림, 나비 비행과 날갯짓 |

새 자산은 Blender에서 제작·편집하고 FBX로 내보냈으며, 회전·흔들림·부유·날갯짓은 Unity의 전용 환경 컴포넌트에서 구현했다. **애니메이션 클립 20개를 Blender에서 만든 것이라는 의미는 아니다.** 기존 CC0 Kenney 자료와 v42 공통 색상·정점 색상 제작 방식을 이어 쓰며, 열매나무는 기존 허가된 나무 메시를 기반으로 한다.

- 개인 마을: 새 환경 인스턴스 **46개**, 움직임 요소 **20개**.
- 가족 광장: 새 환경 인스턴스 **45개**, 움직임 요소 **19개**.
- 실제 브라우저의 개인 마을 초기 장면: 기존 환경과 합쳐 native 메시 인스턴스 **302개**.
- 신규 카탈로그 삼각형 수: **27,520개**. 개인 마을에 배치된 추가 환경은 **39,988개**의 삼각형을 사용한다.

온실·배·의자 등이 독립된 신규 학습 게임이나 조종·탑승 시스템으로 추가된 것은 아니다. 기존 학습과 놀이를 방해하지 않는 환경·움직임 확장이다.

## 2. 검수 중 수정한 부분

온실 지붕의 경사 방향을 바로잡고, 앞을 가리던 기존 나무의 크기를 낮췄다. 풍차 날개에는 천 패널을 더해 실루엣을 보강했다. 또한 기존 ‘꽃 초원’ 산책 목적지와 온실의 이동 경계가 겹치던 부분을 찾아 온실을 뒤로 옮겼다.

건물·큰 구조물에는 명시적인 이동 경계를 적용한다. 새 수초·꽃·물결 등 장식의 클릭 충돌체는 비활성화해 기존 건물·연못의 터치 입력을 가로채지 않게 했다. 꽃 아치는 통로 전체가 아니라 두 기둥만 이동 경계로 처리했다.

‘움직임 줄이기’에서는 환경 부품이 정적인 기본 자세로 돌아간다. 창이 비활성화되면 새 환경 애니메이션 업데이트를 멈추며, 멀리 있는 장식은 거리 기준으로 움직임 갱신을 제한한다. 이는 구현된 처리 정책이며 실기기 FPS나 배터리 절감량을 측정한 결과는 아니다.

## 4. 검증 및 한계

| 검증 | 결과 |
|---|---|
| Unity 새 실행본 빌드 | Succeeded, 빌드 보고서 오류 0·경고 0 |
| 18개 신규 자산 | FBX 메시·정점 색상·크기·Prefab 카탈로그 검증 |
| 개인 마을/가족 광장 × 태희/세희 | 4개 장면 검사 |
| 학습·놀이 목적지 접근 | 11개 목적지 × 4개 장면, 44건 경로 검사 통과 |
| 자유 산책 | 5개 기존 목적지 × 4개 장면의 통행·경로 검사 통과 |
| 움직임 검사 | Unity Editor에서 시간에 따른 변화 및 reduced-motion 기본 자세 유지 검사 |
| 브라우저 움직임 | 태블릿·휴대전화 크기의 Chromium에서 실제 회전값 변화와 UI의 움직임 줄이기 전환 검사 |
| 학습·놀이 | 3D 건물 직접 터치 → 문제 응답 → 연못 → 정원 검사 |
| 기존 학습 회차 | 태희 5문항·세희 3문항 완료 및 다음 학습 검사 |
| 기록 병합 | 모의 RPC의 독립 브라우저 2개, 합성 학습 시도 5건, 동시 충돌 2건·재시도·중복 방지 검사 |

**검증 환경의 제한:** Chromium 터치 에뮬레이션과 소프트웨어 WebGL을 사용했다. 실제 갤럭시·iPad의 GPU, Safari, 발열, 메모리, FPS를 검증한 것은 아니다. 기록 병합은 모의 서버 시험이며 실제 가족 기기의 운영 데이터로 시험한 것이 아니다. 운영 Supabase 요청은 브라우저 시험에서 차단했다.

현재 실행본과 검사 결과의 일치는 `webgl-build-manifest.json`의 네 실행 파일 SHA-256으로 검증한다. v42 전용 바이너리 검사는 그 버전의 과거 검사로 보존하고, 전체 검사에서는 현재 v43의 바이너리·경로·기능·움직임 증거를 검증하는 `check-habitats-v43.mjs`를 사용한다.

```sh
npm run check
npm run check:habitats:v43
NATIVE_QA_ORIGIN=http://127.0.0.1:4633 npm run qa:habitats:v43
READABLE_QA_ORIGIN=http://127.0.0.1:4633 npm run qa:refactor
CLOUD_QA_ORIGIN=http://127.0.0.1:4633 npm run qa:cloud:canonical
```

## 5. 보존·저장·배포

WebGL 실행 파일 4개 합계는 **22,412,321 → 22,748,393바이트**로 **336,072바이트(약 1.50%) 증가**했다. 이는 전송 파일 크기이며 메모리 사용량·FPS를 의미하지 않는다.


`games/`, `platform/progress.js`, `platform/irt.js`, `platform/rewards.js`, `platform/cloud-sync.js`, `supabase/`는 이번 변경에서 수정하지 않았다. 태희·세희의 기록·재화·가족 연결을 초기화하지 않았다.

Blender 편집 원본 `habitat-elements-v43.blend`, FBX 18개, Unity Prefab, 환경 C# 코드와 검사 자료는 **비공개 Unity 소스 저장소**에 보존한다. 공개 웹 저장소에는 새 WebGL 실행 파일, 제작 스크립트와 합성 상태 검수 자료만 반영한다. 비공개 Unity 소스를 공개 저장소로 옮기지 않는다.

두 저장소의 개발 브랜치 이름은 `feat/blender-habitats-v43-20261104`이다. **운영 main 병합이나 GitHub Pages 정식 배포는 하지 않았다.** 실기기 검수와 실제 가족 기록 승계 확인이 정식 전환의 남은 조건이다.
